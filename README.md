# 🌊 AIWave — AI SaaS Platform

**AIWave** is a full-stack **AI SaaS application** built with the **PERN stack**, offering multiple AI-powered tools through a single platform.

## ✨ Features

* ✍️ **Write Article** — Generate AI-powered articles
* 🔊 **Text to Speech** — Convert text into speech
* 🖼️ **Generate Images** — Create AI-generated images
* 📝 **Grammar Checker** — Check and improve grammar
* 🧹 **Remove Background** — Remove image backgrounds
* ✨ **Remove Object** — Remove unwanted objects from images
* 📄 **Resume Review** — Analyze and review resumes
* 👥 **Community** — Interact and share with the community
* 📊 **Dashboard** — Manage AI tools and usage

### 💎 Free & Premium

* **Free:** Write Article, Text to Speech
* **Premium:** All other AI-powered features

Premium subscriptions and user authentication are managed using **Clerk**.

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Authentication & Subscription:** Clerk
* **Architecture:** PERN Stack
